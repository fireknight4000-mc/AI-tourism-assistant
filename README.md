## Tools used from the homework file

This project uses only the suggested coding approach: **HTML and CSS**, edited in **Visual Studio Code or Notepad++**. The images are original AI-generated illustrations, which the homework document lists as an allowed image option when properly mentioned.

No React, Vite, Node.js, database, API, or JavaScript is needed.

## How to view it

1. Open this folder in Visual Studio Code.
2. Keep the `images` folder beside `index.html`.
3. Double-click `index.html` to open it in a browser.
4. Edit `index.html` for content and `style.css` for colours, layout, and design.
